# Documentation

ARKlector's docs are split by how settled they are, and within that, organized as a life cycle — a piece of clipboard content's path from copy to spoken audio.

* [Foundational](foundational/readme.md) — settled decisions: what the app is, the code philosophy, the architecture.
* [Implementation](implementation/readme.md) — the concrete how, one life cycle stage at a time: acquisition → parsing → synthesis & playback → persistence, plus cross-cutting settings.
* [Proposal](proposal/readme.md) — open, unsettled questions.
