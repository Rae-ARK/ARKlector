## What it is

A Read Aloud app which takes content from clipboard and using TTS reads aloud.

> Early development. ALpha Stage.
> Follow the installation and release links from these official sources. A similar

## Installation

ARKlector can be tracked and updated through [Obtainium](https://github.com/ImranR98/Obtainium).

Obtainium allows users to install and track Android applications directly from their source repositories, without relying on a centralized app store.

**To install:**

1. Install [Obtainium](https://github.com/ImranR98/Obtainium).
2. Click the **Get it on Obtainium** badge above.
3. Confirm the ARKlector application configuration.
4. Obtainium will track the repository for available updates.

Alternatively, download the latest release directly from [GitHub Releases](https://github.com/Rae-ARK/ARKlector/releases/).
